# Bus Booking Application

A desktop-based Bus Booking Application developed in Java using Java Swing for the graphical user interface and MySQL for storing booking records. 
The application allows users to enter passenger details, book bus tickets, and automatically generate a unique booking ID.

# About the Project

The Bus Booking Application provides a simple interface where users can:

. Enter passenger details such as email, address, mobile number, gender, and age.
. Specify source and destination locations.
. Book a ticket with one click.
. Generate a random booking ID.
. Save booking details into a MySQL database.
. Clear all fields or exit the application.
This project demonstrates the integration of Java GUI programming with database connectivity using JDBC.

# Features
📝 Passenger information form
🚌 Source and destination entry
🎫 Automatic booking ID generation
💾 Data storage in MySQL database
🧹 Clear form functionality
❌ Exit application button
⚠️ Validation for empty fields
